# daily-ai-project-2026-11-03-llm-prompt-consistency-auditor
A privacy‑first FastAPI service that runs the same user prompt against multiple LLM providers, stores responses with embeddings, computes token‑level and semantic consistency metrics, and visualises drift in a React dashboard. Includes OpenTelemetry‑enabled observability for latency and error tracking. Build-it-yourself AI/ML project.
